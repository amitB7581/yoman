# סופר יומן

יומן אישי שעובד כאפליקציה (PWA): לוח חודשי עם חגים ותאריך עברי, צ׳ק ליסט, אירועים חוזרים, מצב רוח, מערכת שעות, טבלאות ועוזר AI.

- הנתונים נשמרים במכשיר בלבד (localStorage + IndexedDB לתמונות).
- עובד גם בלי אינטרנט.
- עוזר ה־AI עובד בחינם עם Gemini: מפתח מ־aistudio.google.com/apikey (🔑 הגדרת AI בתחתית העמוד).
- להעברה בין מכשירים: ⬇️ גיבוי במכשיר אחד, ⬆️ שחזור במכשיר השני.

## הרצה מקומית
```bash
python3 -m http.server 8080
```
